# 🌍 Процедурная генерация Terrain - Инструкция

## 📋 Что добавлено:

### 1. **ProceduralGroundTexture** - Процедурная текстура земли
Генерирует реалистичную текстуру травы и почвы с использованием Perlin Noise.

**Возможности:**
- Автоматическая генерация уникальной текстуры для каждой игры (или фиксированный seed)
- Настройка цветов травы (светлая/тёмная) и земли
- Контроль покрытия травы (70% трава, 30% земля по умолчанию)
- Синхронизация между сервером и клиентами (один seed = одинаковая текстура)

### 2. **ProceduralGrassGenerator** - Генератор 3D травы
Размещает модели травы по всей карте процедурно.

**Возможности:**
- GPU Instancing для производительности
- Настройка количества травы (по умолчанию 5000)
- Кластеризация (трава растёт группами, а не равномерно)
- Автоматическое исключение травы рядом с ресурсами
- Рандомные размеры и повороты

### 3. **SimpleGrass** - Простая модель травы
Создаёт крестообразную модель травы из двух плоскостей.

### 4. **Улучшенная генерация ресурсов**
- Рандомные повороты для деревьев и руды (0-360°)
- Рандомные масштабы:
  - Деревья: 0.8 - 1.3x
  - Руда: 0.7 - 1.2x

## 🎯 Настройка (пошагово):

### **Шаг 1: Настройка текстуры земли**

1. Выбери GameObject с Plane (земля) в сцене
2. Добавь компонент **ProceduralGroundTexture**
3. Настрой параметры в Inspector:

```
Texture Settings:
  - Texture Width: 2048 (качество)
  - Texture Height: 2048
  - Noise Scale: 50 (размер пятен травы)
  
Ground Colors:
  - Grass Color Dark: RGB(51, 128, 51) - тёмная трава
  - Grass Color Light: RGB(77, 179, 77) - светлая трава
  - Dirt Color: RGB(102, 77, 51) - земля
  
Variation:
  - Grass Coverage: 0.7 (70% травы)
  - Detail Scale: 200 (детализация)
  - Seed: 0 (0 = случайный каждый раз)
```

4. Запусти игру - текстура сгенерируется автоматически!

---

### **Шаг 2: Создание префаба травы**

1. Создай пустой GameObject → **Hierarchy → Create Empty**
2. Назови его "GrassPrefab"
3. Добавь компонент **SimpleGrass**
4. Настрой параметры:
   - Grass Color: RGB(77, 179, 77)
   - Height: 0.5
   - Width: 0.3

5. **Сделай из него Prefab:**
   - Перетащи "GrassPrefab" из Hierarchy в папку `Assets/Prefabs/`
   - Удали оригинал из сцены (префаб остался в папке)

---

### **Шаг 3: Настройка генератора травы**

1. Найди GameObject "ResourceManager" (или создай новый пустой)
2. Добавь компонент **ProceduralGrassGenerator**
3. Настрой параметры:

```
Grass Settings:
  - Grass Prefab: [перетащи созданный GrassPrefab]
  - Grass Count: 5000 (для начала, можно до 20000)
  - World Size: 500 (должен совпадать с размером карты)
  
Randomization:
  - Min Scale: 0.5
  - Max Scale: 1.5
  - Random Rotation: ✅
  
Distribution:
  - Clumpiness: 0.5 (0=равномерно, 1=кластерами)
  - Noise Scale: 50
  
Exclusion Zones:
  - Resource Exclusion Radius: 2 (трава не будет спавниться рядом с деревьями/рудой)
```

4. Запусти игру - трава сгенерируется автоматически!

---

### **Шаг 4: Настройка ресурсов (деревья и руда)**

ResourceManager теперь имеет дополнительные настройки:

```
Resource Randomization:
  - Random Rotation: ✅
  
  - Random Tree Scale: ✅
    - Min Tree Scale: 0.8
    - Max Tree Scale: 1.3
  
  - Random Ore Scale: ✅
    - Min Ore Scale: 0.7
    - Max Ore Scale: 1.2
```

Каждое дерево и руда будут уникальными!

## ⚡ Производительность:

### Оптимизация травы:
- **5000 объектов** = ~30-40 FPS (средний ПК)
- **10000 объектов** = ~20-25 FPS
- **20000+ объектов** = рекомендуется использовать Unity Terrain с Grass system

### Рекомендации:
1. Начни с 5000 травы
2. Если FPS хороший → увеличь до 10000
3. Используй LOD (Level of Detail) для травы вдали
4. Включи GPU Instancing в материале травы

## 📝 Примечания:

- Все скрипты поддерживают **Mirror networking**
- Используется **единый seed** для идентичной генерации на сервере и клиентах
- Трава **не является Network объектом** (чисто визуальная, каждый клиент генерирует свою)
- Ресурсы (деревья/руда) **синхронизируются по сети**
