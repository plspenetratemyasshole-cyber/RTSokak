# День и Ночь - Инструкция по настройке

## Быстрая настройка

### 1. Добавить систему в сцену

1. В сцене **SampleScene** создай пустой GameObject: `GameObject → Create Empty`
2. Назови его **"DayNightCycle"**
3. Добавь компонент `DayNightCycle` (скрипт в `Assets/Scripts/Environment/DayNightCycle.cs`)

### 2. Настроить Directional Light

Система автоматически найдёт Directional Light в сцене, но можно указать его вручную:
- В инспекторе DayNightCycle, в поле **Directional Light** перетащи твой Directional Light

### 3. Параметры по умолчанию

Система создаст дефолтные настройки автоматически при первом запуске:
- **Cycle Duration**: 1200 секунд (20 минут)
- **Start Time**: 0.25 (6:00 утра)
- Все градиенты и кривые создаются автоматически

### 4. Добавить UI индикатор времени (опционально)

1. В Canvas создай TextMeshPro элемент
2. Добавь на Canvas компонент `TimeOfDayUI`
3. В инспекторе перетащи:
   - TextMeshPro элемент в поле **Time Text**
   - GameObject с DayNightCycle в поле **Day Night Cycle**

## Расписание времени

- **0.00** (00:00) - Полночь
- **0.25** (06:00) - Рассвет
- **0.50** (12:00) - Полдень
- **0.75** (18:00) - Закат
- **1.00** (24:00) - Полночь снова

## Настройка градиентов (если хочешь изменить цвета)

### Light Color Gradient
Цвет солнечного света в течение дня:
- 00:00 - Темно-синий (ночь)
- 06:00 - Оранжевый (рассвет)
- 12:00 - Белый (полдень)
- 18:00 - Красно-оранжевый (закат)
- 24:00 - Темно-синий (ночь)

### Ambient Color Gradient
Цвет окружающего освещения:
- Ночь: тёмный
- День: яркий серый
- Рассвет/Закат: тёплые тона

### Fog Color Gradient (если включён туман)
Цвет тумана в разное время суток

## Настройка кривых (Intensity)

### Light Intensity Curve
Яркость солнца:
- Ночь: 0.1 (слабый лунный свет)
- День: 1.0 (полная яркость)
- Рассвет/Закат: 0.6

### Ambient Intensity Curve
Яркость окружающего света:
- Ночь: 0.3
- День: 1.0
- Рассвет/Закат: 0.6

### Fog Density Curve (если включён туман)
Плотность тумана:
- Ночь: средняя
- Рассвет/Закат: высокая (утренний/вечерний туман)
- День: низкая

## API для скриптов

```csharp
using RTSokak.Environment;

// Получить компонент
DayNightCycle cycle = FindFirstObjectByType<DayNightCycle>();

// Получить текущее время (0.0 - 1.0)
float time = cycle.GetTimeOfDay();

// Установить время
cycle.SetTimeOfDay(0.5f); // Установить полдень

// Получить текущий час (0-23)
int hour = cycle.GetCurrentHour();

// Проверить день или ночь
bool isDay = cycle.IsDay();
bool isNight = cycle.IsNight();
```

## Советы

1. **Производительность**: Система очень лёгкая, не влияет на FPS
2. **Туман**: Можешь отключить туман через `Enable Fog = false`
3. **Скорость**: Измени `Cycle Duration` для быстрого/медленного цикла
4. **Начальное время**: Измени `Start Time` чтобы начать с другого времени суток

## Пример: Изменить длительность цикла на 10 минут

В инспекторе DayNightCycle:
- **Cycle Duration** = 600 (10 минут × 60 секунд)

## Пример: Начать с полудня

В инспекторе DayNightCycle:
- **Start Time** = 0.5
