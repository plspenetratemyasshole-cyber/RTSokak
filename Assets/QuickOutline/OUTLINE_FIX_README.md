# Исправление проблемы с Outline толщиной

## Проблема

Толщина outline увеличивается с ростом координат X/Z объекта. Это происходит потому что оригинальный шейдер Quick Outline использует формулу:

```glsl
viewPosition + viewNormal * -viewPosition.z * _OutlineWidth / 1000.0
```

Где `-viewPosition.z` зависит от расстояния объекта от камеры в view space. Для наклонённой ортографической камеры (типичной для RTS) это означает что объекты дальше от камеры имеют больший `-viewPosition.z` и, следовательно, более толстый outline.

## Решение

Создан исправленный шейдер `OutlineFillOrthographic.shader` который использует константу для ортографических камер:

```glsl
float outlineScale = unity_OrthoParams.w ? 30.0 : -viewPosition.z;
```

## Как применить исправление

### Способ 1: Изменить существующий материал (Рекомендуется)

1. Откройте `Assets/QuickOutline/Resources/Materials/OutlineFill.mat`
2. В Inspector измените Shader с `Custom/Outline Fill` на `Custom/Outline Fill Orthographic`
3. Сохраните

Все Worker'ы автоматически будут использовать исправленный шейдер.

### Способ 2: Через Unity Editor GUI

1. В Project найдите `Assets/QuickOutline/Resources/Materials/OutlineFill`
2. Кликните на материал
3. В Inspector в поле Shader выберите `Custom/Outline Fill Orthographic`

### Проверка

После применения исправления:
- Создайте несколько Worker'ов в разных позициях на карте
- Выберите их (они должны получить зелёный outline)
- **Толщина outline должна быть одинаковой** независимо от позиции

## Технические детали

Исправленный шейдер определяет тип камеры через `unity_OrthoParams.w`:
- `unity_OrthoParams.w = 1` для ортографических камер → используется константа 30.0
- `unity_OrthoParams.w = 0` для перспективных камер → используется `-viewPosition.z` (оригинальное поведение)

Это делает шейдер универсальным для обоих типов камер.

## Альтернативное решение

Если по какой-то причине нельзя изменить материал, можно:

1. Создать копию материала `OutlineFill`
2. Назвать её `OutlineFillOrtho`
3. Применить к ней исправленный шейдер
4. Модифицировать `Outline.cs` чтобы загружать новый материал

Но первый способ проще и не требует изменения кода.
